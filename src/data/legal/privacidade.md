Este site é de caráter institucional e informativo.

## Coleta de informações

Este site não coleta diretamente informações pessoais identificáveis dos usuários, como nome, e-mail ou dados de cadastro.

No entanto, podem ser coletados dados de forma automática e não identificável, incluindo:

- Endereço IP (utilizado para fins de segurança e funcionamento do servidor)
- Informações de navegador e dispositivo
- Dados de navegação agregados (como páginas acessadas e tempo de acesso)

## Uso de cookies

Este site pode utilizar cookies essenciais para o funcionamento adequado da navegação e, eventualmente, ferramentas de análise de acesso (analytics) para fins estatísticos e de melhoria do site.

Esses dados são tratados de forma agregada e não permitem a identificação individual dos usuários.

## Finalidade do tratamento

Os dados eventualmente coletados são utilizados exclusivamente para:

- Garantir o funcionamento do site
- Melhorar desempenho e usabilidade
- Gerar estatísticas de acesso e navegação

## Compartilhamento de dados

Este site não vende, aluga ou compartilha dados pessoais de usuários com terceiros.

Em casos específicos, ferramentas externas de análise podem processar dados agregados de navegação, sem identificação individual.

## Segurança

São adotadas medidas técnicas razoáveis para proteger o site e suas informações contra acessos não autorizados, alterações indevidas ou divulgação indevida.

## Direitos do usuário (LGPD)

Nos termos da Lei Geral de Proteção de Dados (LGPD), o usuário pode solicitar informações sobre o tratamento de dados pessoais eventualmente relacionados a este site, quando aplicável.

## Contato

Para dúvidas relacionadas a esta política, entre em contato pelo canal institucional responsável pelo projeto.
